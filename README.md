# Read me
This Repository provides the code written for the master thesis **Flow in the Snow - Modelling Lateral Flow in Heterogeneous, Non-isothermal Snowpacks**.
--
Provided are the code for solving the full system of equations (*solve_temp_coupled.py*) and for solving the isothermal version of the system (*solve_system_isothermal.py*) and all classes needed for it.
Also provided are two plotting and evaluation Jupyter Notebooks plus a Python file containing evaluation functions.
--
The file *fenicsx_env.yaml* contains the environment in which the program was run.
